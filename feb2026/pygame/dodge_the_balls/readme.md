
# dodge the balls (python/pygame)
A simple survival game built with Pygame where the player avoids incoming enemies for as long as possible.

## Features

- Smooth movement using delta time

- Random enemy spawning

- Increasing difficulty over time

- Collision detection system

- Score based on survival time

# Controls

W / A / S / D → Move

# How to Run

```bash
pip install pygame
python dodge_the_balls.py
```

## What I learned

- Game loop

- Delta time

- Vector math (pygame.Vector2)

- Collision detection (geometry!)

- State management (game_over)

- Spawning systems
